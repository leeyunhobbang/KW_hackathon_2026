# 🚌 노원구 공공순환버스 실시간 도착예측 서비스

> **지역사회 봉사를 위한 소프트웨어 개발**

노원구 공공순환버스의 차량 운행 데이터를 수집하고, GPS 및 속도 데이터를 기반으로 실제 정류장 도착 시점을 분석한다.

수집된 데이터를 활용하여 **지도학습 기반 도착시간 예측 모델**을 구축하고, 기존 시간표와 최근 운행 데이터를 함께 활용하여 사용자에게 더욱 현실적인 버스 도착정보를 제공하는 것을 목표로 한다.

또한 전체 시스템을 **API 중심 구조**로 설계하여 향후 다른 지역의 공공교통 서비스에서도 활용할 수 있도록 확장성을 확보한다.

---

# 1. Project Overview

### 문제

현재 버스 시간표는 정해진 운행 계획을 나타내지만 실제 도착시간은 다음과 같은 요인에 따라 달라질 수 있다.

* 교통 정체
* 신호 대기
* 승객 승하차
* 시간대
* 요일
* 도로 상황
* 정류장별 정차시간

따라서 단순한 시간표만으로는 사용자가 실제 버스의 도착시간을 정확하게 예측하기 어렵다.

### 해결 방법

본 프로젝트에서는 차량의 실제 GPS 및 속도 데이터를 수집하여 버스의 운행 궤적을 분석한다.

```text
차량 GPS / 속도
       ↓
운행 궤적 수집
       ↓
정차 구간 탐지
       ↓
정류장 도착 이벤트 판별
       ↓
실제 운행시간 데이터 구축
       ↓
ETA Prediction Model
       ↓
Transit API
       ↓
Web App
```
